# نتایج بررسی نسخهٔ ۱٫۰٫۰

تاریخ بررسی محلی: ۲۰ اکتبر ۲۰۲۶. این گزارش محدودهٔ اثبات‌شدهٔ نسخهٔ تحویلی را ثبت می‌کند؛ ادعای نبودن تمام باگ‌های ممکن نیست.

## وب

| بررسی | نتیجه |
| --- | --- |
| ساخت تولید Next.js 16.4.2 با Turbopack | موفق |
| TypeScript و lint | موفق |
| آزمون واحد و یکپارچه | ۱۰۳ از ۱۰۳، در ۱۰ فایل |
| گردش مرورگر روی ساخت تولید | ۱۴ از ۱۴؛ بدون شکست، ردشدن یا ناپایداری |
| Lighthouse SEO | ۱۰۰ در هر هشت اجرا |
| Lighthouse دسترس‌پذیری | ۱۰۰ در هر هشت اجرا |
| چک‌لیست داخلی آمادگی کشف محتوا | ۱۸ از ۱۸ |

Lighthouse برای چهار صفحهٔ `/`، `/guide`، `/about` و `/privacy`، هر کدام در موبایل و دسکتاپ اجرا شد. امتیاز اولیهٔ SEO صفحهٔ اصلی در هر دو حالت ۵۴ بود. برای سه صفحهٔ جدید، امتیاز اولیهٔ ۵۴ ادعا نمی‌شود. در این بررسی فقط SEO و دسترس‌پذیری اندازه‌گیری شده‌اند؛ امتیاز عملکرد موبایل ادعا نشده است.

چک‌لیست کشف محتوا، معیار داخلی این پروژه است و امتیاز جهانی GEO یا معیار Google نیست. دامنهٔ واقعی، HTTPS میزبان، خزش، نمایه‌شدن، رتبه یا ارجاع موتورهای هوش مصنوعی بررسی نشده‌اند. برای استقرار، `SITE_URL` را پیش از build به origin دامنهٔ واقعی تنظیم کنید.

اسکریپت بررسی در `scripts/audit-discovery.mjs` قابل اجرا است. حساب شخصی و مسیرهای ورود، راه‌اندازی حساب و API از نمایه‌سازی منع شده‌اند؛ کنترل دسترسی مستقل از noindex انجام می‌شود.

ارسال پیامک واقعی، زمان‌بند خارجی، سرور چندنمونه‌ای و بار توزیع‌شده در این تحویل آزموده نشده‌اند. حالت console پیامک فقط برای توسعه است. نسخهٔ وب به سرور Node.js و فضای پایدار SQLite نیاز دارد.

## اندروید

| مشخصه یا بررسی | نتیجه |
| --- | --- |
| شناسهٔ برنامه | `ir.daftarsetareh.offline` |
| حداقل اندروید / target API | Android 8.0 / API 26؛ target API 36 |
| آزمون واحد | ۲۰ از ۲۰ |
| بررسی بومی روی شبیه‌ساز API 34 | ۶۵ از ۶۵؛ حالت پرواز روشن، Wi-Fi و داده خاموش |
| بررسی پس از بستن کامل و راه‌اندازی مجدد | ۱۱ از ۱۱ |
| lint | صفر خطا؛ دو هشدار سازگاری API با استفادهٔ محافظت‌شده |
| مجوزهای Manifest | هیچ مجوزی، از جمله INTERNET، درخواست نشده است |
| امضای APK | RSA 3072، APK Signature Scheme v2؛ debuggable خاموش |

گوشی فیزیکی و اجرای برنامه روی API 26 و API 36 آزموده نشده‌اند. جریان‌های انتخاب فایل/چاپ همهٔ ارائه‌دهندگان اندروید و چاپگر فیزیکی را پوشش نمی‌دهند. آزمایش با دادهٔ ساختگی و بستهٔ جداگانهٔ QA انجام شد.

پس از آزمون اجرایی، فقط دو فایل متنی مجوز کتابخانه به APK افزوده شدند؛ `classes.dex`، manifest باینری و منابع اجرایی نسخهٔ نهایی با نسخهٔ آزموده‌شده بایت‌به‌بایت یکسان‌اند.

APK نهایی: `daftar-setareh-1.0.0-offline.apk`، اندازهٔ ۷۶۹٬۸۴۵ بایت. SHA-256:

```text

```

اثر انگشت SHA-256 گواهی امضای عمومی:


برنامه مستقل و آفلاین است. ورود پیامکی، همگام‌سازی ابری و اعلان زمان‌بندی‌شده ندارد. JSON پشتیبان رمزگذاری نشده است؛ بازیابی فقط پس از اعتبارسنجی و تأیید، در یک تراکنش انجام می‌شود. سقف ورودی ۵ مگابایت و ۲۰ هزار رکورد است. پیش از حذف برنامه از اطلاعات پشتیبان بگیرید. کلید خصوصی امضا و اطلاعات شخصی در مخزن منتشر نشده‌اند.
