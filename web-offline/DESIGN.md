# دفتر سادهٔ دانش‌آموز

Baseline reviewed: `android-home.png`, release v1.0.0. The purple hero dominated the viewport; repeated rounded cards and five equal-weight actions obscured the first useful task. Navigation, spacing and graph decoration increased work before entering a study record.

Contract: Today answers “what should I do next?” and offers one primary “ثبت مطالعه” button. Today, Plan, Progress and More are the only primary destinations. Exams, report cards, subject management and backups are secondary. The interface uses readable local Vazirmatn, ink on warm near-white, teal emphasis, restrained borders and a narrow notebook-like desktop layout. On mobile navigation stays at the bottom; 320px layouts remain single-column. Real data, empty states and readable tables replace decorative card grids. All actions have visible names, keyboard focus, validated forms and explicit destructive confirmation. Native modal dialogs retain focus; all persistence succeeds before success messages appear.

The static web edition stores a separate notebook in this browser. It does not claim account authentication, server synchronisation or background reminders. Version-1 backups share the Android offline schema for explicit transfer. Never clear a browser's data before downloading a backup.
