# Daftar Setareh — native offline Android

See [README-fa.md](README-fa.md) for the complete Persian feature guide, source layout, build, signing, testing and backup instructions.

This is a standalone Java/SQLite Android application, not a localhost WebView. Minimum Android 8.0 / API 26; compile/target API 36. Release signing keys and personal databases are excluded from the source archive.

Version 1.1.0 introduces a quieter teal interface, a focused Today screen, five short navigation destinations, record overflow menus, and collapsed optional form details. Existing SQLite data and version-1 backups remain compatible.
