# دفتر ستاره — اندروید مستقل و آفلاین

این پوشه یک برنامهٔ بومی اندروید با Java و APIهای خود اندروید است. WebView، localhost، رایانه یا سرور برای استفاده لازم نیست. اطلاعات در SQLite خصوصی همان برنامه نگهداری می‌شود. نسخهٔ نصب‌شدنی با نام **دفتر ستاره** و شناسهٔ `ir.daftarsetareh.offline` ساخته می‌شود.

## رابط ساده‌تر در ۱٫۱٫۰

صفحهٔ «امروز» زمان مطالعه و یک دکمهٔ اصلی «ثبت مطالعه» دارد. پنج مقصد پایین صفحه، «امروز»، «مطالعه»، «برنامه»، «نمره‌ها» و «بیشتر» هستند. کارنامه، هدف‌ها، درس‌ها و تنظیمات از «بیشتر» باز می‌شوند. ویرایش و حذف هر مورد در منوی سه‌نقطهٔ همان کارت است؛ حذف همچنان تأیید می‌خواهد.

یادداشت‌ها، ضریب آزمون و تکرار برنامه فقط با بازکردن بخش اختیاری نمایش داده می‌شوند. کارها هر خط یک عنوان هستند و از فهرست مطالعه تیک می‌خورند. ویرایش متن کارهای موجود، تیک انجام‌شدن و ارتباط درسشان را حفظ می‌کند. رنگ اصلی سبزآبی، زمینه روشن و نوشته‌ها سرمه‌ای هستند. همهٔ اطلاعات و فرمت پشتیبان نسخهٔ ۱ حفظ شده‌اند؛ این به‌روزرسانی مهاجرت پایگاه داده ندارد.

## امکانات

- شروع با دفتر خالی و پروفایل محلی؛ ساخت نمونه فقط با انتخاب صریح کاربر و فقط روی دفتر خالی.
- درس‌های رنگی با ویرایش و بایگانی؛ سوابق درس بایگانی‌شده حفظ می‌شود.
- گزارش روزانه با دقیقهٔ چند درس، کارهای انجام‌شده/در انتظار، مرور، تمرین، چالش، یادداشت و هدف فردا.
- آزمون با نمرهٔ اعلام‌نشده، مقیاس خام متفاوت و ضریب اختیاری؛ ابتدا تبدیل به درصد و سپس میانگین وزنی هر درس. معدل کل، میانگین برابر درس‌های نمره‌دار است. صفر واقعی محاسبه می‌شود؛ نمرهٔ خالی محاسبه نمی‌شود.
- برنامهٔ مطالعه، ویرایش و تکمیل مستقل جلسه‌ها، تکرار در روزهای هفته تا ۱۲۰ روز و حذف تراکنشی مجموعه. جلسه باید پیش از نیمه‌شب همان روز پایان یابد.
- هدف مطالعه، کار و میانگین با دورهٔ روزانه/هفتگی/ماهانه؛ محاسبه فقط در اشتراک بازهٔ معتبر هدف و دورهٔ جاری؛ نشانه‌های پیشرفت ۲۵/۵۰/۷۵/۱۰۰ درصد.
- تاریخ شمسی واقعی با ICU اندروید، اعتبارسنجی کبیسه و روزهای ماه. هفته از شنبه شروع می‌شود؛ ماه کارنامه، ماه شمسی است.
- کارنامهٔ هفتگی/ماهانه، مقایسهٔ دورهٔ قبل، PDF واقعی با متن فارسی، چاپ بومی اندروید و اشتراک متن.
- ذخیرهٔ JSON در محل انتخابی کاربر و بازیابی پس از اعتبارسنجی و تأیید صریح؛ جایگزینی کامل در یک تراکنش، با بازگشت کامل در صورت خطا.

ورود پیامکی، همگام‌سازی ابری و اعلان زمان‌بندی‌شده در این نسخه وجود ندارد. برنامه هیچ مجوز شبکه، مخاطب یا دسترسی گسترده به فایل‌ها درخواست نمی‌کند. انتخاب فایل با Storage Access Framework انجام می‌شود. فایل JSON رمزگذاری نشده و حاوی اطلاعات شخصی است؛ آن را در محل مطمئن نگه دارید. حذف برنامه/پاک‌کردن داده‌های آن، دفتر محلی را حذف می‌کند؛ پیش از آن پشتیبان بگیرید.

پشتیبان نسخهٔ ۱ بین نسخهٔ وب آفلاین و اندروید قابل انتقال دستی است: در مبدأ از تنظیمات پشتیبان بگیرید، فایل را به دستگاه مقصد ببرید و از تنظیمات مقصد بازیابی کنید. بازیابی پس از تأیید، همهٔ اطلاعات فعلی مقصد را جایگزین می‌کند؛ ابتدا از مقصد هم پشتیبان بگیرید. این انتقال، همگام‌سازی خودکار نیست. سازگاری هر دو جهت با خروجی واقعی مرورگر و Android Store و مقایسهٔ تمام فیلدهای نمونه‌های ساختگی آزموده شده است.

## ساخت

پیش‌نیازها: Windows/PowerShell، JDK 17 یا بالاتر (JBR اندروید استودیو مناسب است)، Android SDK با platform 36 و build-tools 36، Gradle 9.3.1. Gradle Wrapper در سورس هست؛ نخستین ساخت ممکن است دانلود نیاز داشته باشد. AGP برابر 9.1.1 و حداقل اندروید 8.0 / API 26 است. `targetSdk` برابر 36 است. اجرای برنامه به WebView یا سرور نیاز ندارد؛ زنجیرهٔ ساخت ممکن است کتابخانه‌های زمان اجرا مانند کتابخانهٔ استاندارد Kotlin را در APK قرار دهد.

```powershell
cd android
.\build.ps1 -Configuration Debug
# اگر همهٔ وابستگی‌های ساخت از قبل کش شده‌اند:
.\build.ps1 -Configuration Debug -Offline
```

APK آزمایش در `app/build/outputs/apk/debug/app-debug.apk` است. شناسهٔ آن پسوند `.qa` دارد تا از نسخهٔ اصلی و داده‌هایش مستقل باشد.

برای release باید **کلید خودتان** را نگه دارید. فایل تنظیم خصوصی JSON را بیرون پوشهٔ سورس بسازید؛ فیلدهایش `keystore` (مسیر کامل PKCS12/JKS)، `storePassword` و `keyPassword` هستند. alias باید `daftar-setareh` باشد. رمزها را در مخزن، ZIP یا گزارش منتشر نکنید.

```powershell
.\build.ps1 -Configuration Release -SigningConfig 'D:\private\signing-private.json'
```

APK در `app/build/outputs/apk/release/app-release.apk` است. برای آپدیت برنامهٔ نصب‌شده، شناسهٔ برنامه و **همان کلید امضا** باید حفظ شود. کلید امضای نسخهٔ تحویلی، برای امنیت در ZIP سورس قرار نگرفته؛ توضیح محل محلی آن در بستهٔ تحویل آمده است. از کلید و رمزها جداگانه و امن پشتیبان بگیرید. از دست‌دادن کلید مانع آپدیت مستقیم همان نصب خواهد شد؛ حذف نصب نیز دادهٔ دفتر را پاک می‌کند.

## آزمون

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:lintRelease :app:assembleDebug :app:assembleDebugAndroidTest --offline --no-daemon --max-workers=1
adb -s emulator-5584 install -r app/build/outputs/apk/debug/app-debug.apk
adb -s emulator-5584 install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb -s emulator-5584 shell am instrument -w ir.daftarsetareh.offline.qa.test/ir.daftarsetareh.offline.QARunner
# بررسی ماندگاری پس از بستن کامل برنامه:
adb -s emulator-5584 shell am force-stop ir.daftarsetareh.offline.qa
adb -s emulator-5584 shell am instrument -w -e persistOnly true ir.daftarsetareh.offline.qa.test/ir.daftarsetareh.offline.QARunner
```

QARunner باید فقط روی دستگاه/شبیه‌ساز تست اجرا شود: پایگاه `qa-domain-tests.db` را موقتاً می‌سازد و پاک می‌کند و در بستهٔ جداگانهٔ `.qa` دادهٔ تست وارد می‌کند. هیچ داده‌ای از وب‌سایت یا نسخهٔ release را دست نمی‌زند. تست‌ها شامل تزریق خطای واقعی SQLite برای اطمینان از بازگشت کامل import و حذف مجموعه هستند. گزارش‌های JUnit و lint در `app/build/reports/` قرار می‌گیرند.

## ساختار

`Core.java`: محاسبات خالص و تکرار؛ `Dates.java`: ICU و تاریخ شمسی؛ `Store.java`: SQLite و اعتبارسنجی/پشتیبان؛ `MainActivity.java`: میزبان؛ `Ui.java`: اجزای مشترک؛ `Forms.java`: فرم‌ها؛ `Screens.java`: صفحه‌ها؛ `ReportData.java`: محاسبهٔ کارنامه؛ `Exporter.java`: PDF/چاپ/فایل انتخابی.

فونت وزیرمتن از مخزن رسمی سازنده گرفته شده و با SIL Open Font License 1.1 همراه فایل `app/src/main/assets/OFL-Vazirmatn.txt` توزیع می‌شود. فونت ویندوز یا داده/کلید شخصی در سورس تحویل داده نشده است.

مستندات API: [SQLite](https://developer.android.com/training/data-storage/sqlite)، [انتخاب فایل](https://developer.android.com/training/data-storage/shared/documents-files)، [چاپ](https://developer.android.com/training/printing/custom-docs)، [امضای برنامه](https://developer.android.com/studio/publish/app-signing).
